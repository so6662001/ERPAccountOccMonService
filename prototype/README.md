# 高保真原型 · ERP 账务正确性监测平台（云化多租户）

本目录是产品的**高保真 HTML 原型**，用于评审确认产品形态与交互，再以 **Java + Vue3（Element Plus）** 落地。
纯静态、无外部依赖，双击任意 `.html` 即可在浏览器查看；建议从 `index.html` 进入，页面间已贯通导航。

## 页面清单

| 页面 | 文件 | 说明 |
|---|---|---|
| 监控总览 | `index.html` | 多客户/租户健康度、通过率、失败分布、最新告警 |
| 客户与租户 | `tenants.html` | **两种隔离模式**（独立数据库 / 租户隔离），含**行业 / 会计期间 / SLA** 字段 |
| 客户接入配置 | `tenant-edit.html` | 客户全字段配置：基本信息 / 数据源 / **会计期间** / **SLA** / **关联产品与部署版本** / 规则集 |
| 检查规则 | `rules.html` | 规则列表，新增**适用产品 / 生效版本**列，随迭代**增删改** |
| 规则编辑 | `rule-edit.html` | 声明式编辑器 + **模板来源** + **适用产品/服务器** + **版本生效条件** + 调度/告警/YAML |
| 规则模板库 | `rule-templates.html` | 按行业沉淀的**标准规则集**，**一键套用**到客户/租户群，模板自带版本 |
| 检测结果 | `results.html` | 一次运行详情，**违规单据下钻**（借贷不平、应付勾稽、成本偏差…） |
| 数据源 | `datasources.html` | 多客户/租户**只读**连接管理、探活、只读副本优先 |
| 检测任务 | `tasks.html` | 定时/结账事件/CI 门禁多触发，按客户与租户**并行调度** |
| 基线管理 | `baselines.html` | 不变量指标基线快照、审定、**迭代回归对比** |
| 灰度发布 | `rollout.html` | 规则/模板变更**按服务器/客户/租户分批灰度生效**，观察达标再扩量，异常自动回滚 |
| 模板差异对比 | `template-diff.html` | 模板升级 vs 客户本地的**差异对比 + 选择性同步**（保留本地微调） |
| 告警中心 | `alerts.html` | 告警聚合、处理闭环、**企业微信推送状态** |
| 企业微信通知 | `wecom.html` | 企业微信接入配置、推送策略、按客户分流、**消息卡片预览** |
| 权限与审计 | `audit.html` | 角色权限矩阵 + 关键操作**全程留痕** |
| 登录 | `login.html` | 账号密码 / 企业微信扫码登录（平台入口，含交互切换） |
| 快速接入向导 | `onboarding.html` | 5 步接入向导（接入客户→数据源→套用规则集→告警→启动检测） |
| 移动端告警 | `mobile-alerts.html` | 手机端告警列表 + 详情（认领/转交/闭环），与企业微信推送互补 |

> 入口：`login.html` 为平台入口；`rule-edit.html` 的「测试运行」按钮可弹出**测试运行结果弹窗**（含命中客户试跑结果与失败明细，交互可点开/关闭）。

## 本轮优化要点（按评审反馈）

- **客户/租户字段补全**：新增 `所属行业`、`会计期间`（期间制度/当前期间/结账日/历史锁定）、`SLA 等级`（可用性目标/检测频率/告警响应时长）。见 `tenants.html` / `tenant-edit.html`。
- **规则模板库 / 行业规则集一键套用**：新增 `rule-templates.html`，按行业（制造/商贸/零售/SaaS/物流/通用）沉淀标准规则集，可一键下发。
- **规则与产品升级版本挂钩**：每条规则可设「适用产品线 + 生效版本表达式（如 `≥ v4.0`、`v3.2 ~ v9.0`）+ 适用服务器」。平台按客户**当前部署版本**自动判定是否执行——旧版本不误报、新规则随升级自动生效，天然对齐产品 N 次迭代。见 `rule-edit.html` / `rules.html`。

## 第二轮优化（按评审反馈）

- **灰度 / 分批生效**：`rollout.html`，支持按服务器 / 客户 / 租户百分比分批，每批设观察期，达标自动（或人工）推进，误报率/错误率超阈值自动回滚并推送企业微信。
- **模板差异对比 + 选择性同步**：`template-diff.html`，模板升级与客户本地配置逐条 diff（新增/修改/弃用/本地自定义），勾选式选择性同步，默认保留本地微调，同步后可走灰度。
- **客户字段再补充**：`tenant-edit.html` 新增 **多账簿**（主/IFRS/税务账簿独立监测）、**多币种**（本位币 + 外币折算校验）、**合并报表口径**（纳入集团合并、合并层级、内部交易抵消规则集）。
- **补齐运维页面**：数据源、检测任务、基线管理、权限与审计。

## 已覆盖的关键诉求

1. **云化多客户 / 双隔离模式**：独立数据库 + 租户隔离（`tenant_id`）统一纳管，见 `tenants.html`。
2. **高效检测**：租户隔离采用「单 SQL 跨全租户聚合扫描 + 仅异常租户下钻」，避免逐租户 N 次查询；独立库按客户并行调度。
3. **规则可人为增改 / 持续演进**：声明式规则 + 版本管理 + 规则集下发，应对软件与账务的持续迭代，见 `rules.html` / `rule-edit.html`。
4. **发现问题即企业微信推送**：失败按级别聚合告警，自动推送企业微信并 @责任人，见 `wecom.html` / `alerts.html`。
5. **迭代回归防护**：关键不变量指标与已审定基线对比，发现"本不该变却变了"，见 `rule-edit.html` 回归区与告警示例。

## 落地建议（Java + Vue3）

- 前端：Vue3 + Element Plus + Pinia + ECharts，按本原型还原。
- 后端：Spring Boot 调度（XXL-Job / Quartz）+ 多数据源（动态 DataSource，按客户/租户路由，全程只读）+ 规则引擎（声明式 SQL 校验）+ 企业微信推送（群机器人 Webhook / 自建应用）。
- 规则与基线持久化于平台库；与本仓库根目录的 `erp_acc_monitor` 校验引擎方法论一致（见 `docs/ARCHITECTURE.md`）。
